# c_Obsidian · Атлас идей / Idea Atlas / 思想地图

Версия 0.2.1. Локальный спутник Obsidian: API, CLI, интерфейс RU/EN/简体中文,
карты Markdown-связей и изображения. [Русский](docs/README_RU.md) ·
[English](docs/README_EN.md) · [简体中文](docs/README_ZH.md).

Это самостоятельное приложение, открывающее обычную папку Markdown. Оно не
устанавливает и не изменяет Obsidian или плагин Maps of the Ideaverse.
Файлы заметок можно открыть в Obsidian как обычное хранилище.

## Контейнер и внешний доступ

Для RouterA и внешнего HTTPS добавлены постоянный вход, отзываемые сессии, Gunicorn и Caddy. [План и чеклист](docs/PLAN_CHECKLIST_RU.md) · [Развёртывание](docs/DEPLOYMENT_RU.md).

Исправления TLS, порта 18444 и проверок входа: [RouterOS HTTPS](docs/ROUTEROS_HTTPS_RU.md).

## Быстрый запуск

Нужен локально установленный Python 3.10+. Внешних пакетов нет.
В **локальной** папке `c_Obsidian`:

```powershell
py -3 -B obsidian.py --lang ru serve --write --open
```

Откроется браузер с демохранилищем: 47 вымышленных заметок и три авторские
иллюстрации. Верхние кнопки **RU · EN · 中文** переводят всё меню, названия
карт, формы, подсказки и сообщения. Язык запоминается в браузере. Содержимое
самих заметок остаётся в оригинале. Верхняя панель закреплена при прокрутке.

Windows-запускатор из локальной папки: `./Start-c_Obsidian.ps1`.
Параметры: `-Language ru|en|zh`, `-VaultPath "C:\MyNotes"`, `-Port 8765`,
`-ReadOnly`. Настройки исполнения PowerShell запускатор не меняет.

Остановить приложение: `Ctrl+C` в его терминале. Для своего хранилища:

```powershell
py -3 -B obsidian.py --vault "C:\MyNotes" --lang ru serve --open
```

Без `--write` API и интерфейс работают в режиме чтения. CLI-команды `create`
и `photo` сами являются явным запросом на добавление файлов. Существующие
заметки и изображения никогда не перезаписываются. Удаления и редактирования
через API нет. Кнопка «Обновить» заново читает хранилище.

## Что входит

- **Рост идей / Emergence / 思想生长** — пять объяснимых уровней, дата или папки.
- **Звёздное поле / Starfield / 星空** — ближайшие хабы по существующим связям.
- **Притяжение / Gravity / 引力** — те же уровни на пяти кольцах.
- **Смысловые роли / Sensemakers / 思维角色** — четыре роли по структуре заметки.
- **Изображения / Images / 图片** — локальные PNG, JPEG, GIF, WebP; загрузка и
  просмотр из `![[assets/photo.png]]` или `![caption](assets/photo.png)`.
- Чтение оригинала, обратные ссылки, поиск, хронология появления, JSON-граф.
- Локальный HTTP API: [справочник](docs/API.md), [OpenAPI](openapi.json).
- CLI: [команды и примеры](docs/CLI.md).

## Безопасный запуск из общего проекта

`Source` на SMB не исполнять напрямую. Открывайте локальную проверенную копию
модуля. [Инструкция переноса](docs/INTEGRATION_RU.md) перечисляет минимальные
файлы и проверку SHA-256. Корень всего AI_WorckBook не выбирается хранилищем.
`Pass`, `Private`, `Runtime`, скрытые каталоги, symlink/junction исключены.
Для пилота используйте отдельную папку заметок.

Сервис привязан к `127.0.0.1`, использует ключ текущего запуска, проверяет Host
и Origin. Ключ в ссылке запуска удаляется из адресной строки и не сохраняется
в файлах. При запуске без `--open` ссылка с ключом печатается для ручного
открытия: не публикуйте её. Приложение не обращается к облаку, ИИ, CDN или
внешним изображениям. Ссылка на оригинальный плагин открывается только по клику.

## Ограничения

Это первая самостоятельная реализация. Правила уровней c_Obsidian отличаются
от алгоритма Ideaverse: [точная политика](docs/POLICY.md). Нет 3D, Bases,
истории прошлых состояний ссылок и автоматического перевода текста заметок.
Хронология показывает появление по `created`/имени файла **с текущими связями**.
Файловые даты не используются. Поддержан ограниченный синтаксис Markdown и
только верхние скалярные поля frontmatter. Каждый scan читает и хеширует все
допустимые Markdown-файлы; кэш в памяти экономит разбор неизменённых файлов.
Лимит: 20 000 заметок, 2 МиБ на заметку, 12 МиБ на изображение. Граф большого
хранилища может работать медленно; 10 000+ заметок не тестировались.

## Проверка

```powershell
py -3 -B -m unittest discover -s tests -v
node --check web/app.js
```

Node нужен только для необязательной проверки синтаксиса JavaScript.

## Источники

Идея карт: [Maps of the Ideaverse, Nick Milo](https://github.com/nickmilo/ideaverse-maps).
Код и изображения плагина не копировались. У Obsidian есть собственный
[официальный CLI](https://help.obsidian.md/cli); команды этого модуля относятся
к **c_Obsidian**, работают непосредственно с Markdown и не требуют запущенного
Obsidian. [Vault API Obsidian](https://docs.obsidian.md/Plugins/Vault) относится
к разработке плагинов внутри приложения; наш HTTP API описан отдельно.
