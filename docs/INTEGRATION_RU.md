# Перенос c_Obsidian в AI_WorckBook

Это инструкция к кандидату. Она не назначает интегратора и не разрешает
развёртывание. Основные правила workspace и ADD_Update сохраняются.

## Минимальный scope

Добавить только `Source/c_Obsidian/**` из `files/Source/c_Obsidian/` заявки.
База для новых файлов: `ABSENT`. Не менять индексы, общий runtime, scheduler,
модели, другие модули, установленный Obsidian или его плагины в этом пакете.
Индексацию при необходимости оформить отдельно по действующему порядку.

## Проверка перед переносом

Назначенный оператором интегратор проверяет текущее поручение/writer/handoff,
что целевая папка отсутствует, список и SHA-256 файлов в `FILES.sha256.json`,
локальные проверки и ограничения в `REQUEST.md`. Отсутствующий или неполный
журнал activity не доказывает свободный scope. Статусы source, local test,
live deployment и operator acceptance остаются отдельными.

## Минимальный набор для локального запуска

Программу из SMB нельзя запускать напрямую. Скопировать в новую локальную
папку только эти runtime-файлы, сохраняя относительные пути:

```text
obsidian.py
obsidian_core.py
openapi.json
web/index.html
web/app.js
web/style.css
```

Для тестов дополнительно `tests/test_obsidian.py`. Для демонстрации отдельно
скопировать **только** перечисленные в manifest файлы `demo-vault/` из этого
пакета: 47 Markdown и три PNG. Весь AI_WorckBook или соседние каталоги не
копировать. Сверить SHA-256 каждого оригинала и копии с manifest. Временные
ключи, `.env`, `Pass`, `Private` и runtime не копировать.

Текущая проверенная локальная копия указана в `REQUEST.md`. Собственные
vault-пути передаются явно через `--vault`; сеть и автозапуск не настраиваются.
Для устойчивой установки оператор выбирает постоянный локальный каталог;
временная проверка сама такой установки не подтверждает.

В локальной копии:

```powershell
py -3 -B -m unittest discover -s tests -v
py -3 -B obsidian.py --lang ru serve --write --open
```

После переноса интегратор оформляет `REVIEW.md` и пишет отдельную квитанцию
проверки результата. Автор пакета не заполняет `REVIEW.md` за интегратора.

## Откат

Остановить **свой** локально запущенный процесс через `Ctrl+C`. Новые заметки
пользователя сохраняются отдельно от программы. Удаление программных файлов
или заявки не выполняется автоматически. Отмену добавления модуля оформляет
интегратор только в точном scope и после проверки, что в нём нет новых данных.
