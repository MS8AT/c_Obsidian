# c_Obsidian 0.3.1-prism-authlock

Superseding-кандидат для review; live RouterOS-образ этой заявкой не заменяется.

## Что входит

- API и веб-интерфейс версии `0.3.0`.
- Сборка `0.3.1-prism-authlock` с лабораторией «Призма различений».
- Источник правил и журналов Prism в `prism_core.py`.
- Контракт `/api/health`, возвращающий `version`, `build_version` и `auth`.
- Dockerfile для Linux/amd64 и два публичных Caddy-конфига.
- `/api/login` считает неверные пароли, после 10-й ошибки блокирует remote на 30
  минут и возвращает `429` с `Retry-After` в секундах.

## Происхождение

Кандидат наследует исходный пакет `20261112T_codex_cobsidian_prism_routera_3f20a6d1`
и supersedes его только для auth-lockout правки. Базовая сверка выполнена с
read-only источником RouterA-контейнера `c-obsidian-0.3.0-prism` и GitHub main
`97142e69b06cab2918df394ab6835b9d79c58c34`. GitHub main содержит более старую
ветку 0.2.1, поэтому его несовместимые тесты и документация в этот минимальный
кандидат не переносились.

Dockerfile восстановлен по публичной OCI-метаинформации live-образа; сам
пользовательский runtime в образ не входит.

## Что намеренно не публикуется

Каталоги и данные `/vault`, `/state`, `/data`, `/config`, аккаунты, cookies,
session DB, пароли, ключи, `.env`, журналы и RouterA secrets не являются частью
исходников и должны оставаться на runtime-устройстве.

## Проверка

Локальный WSGI smoke проверяет точный health-контракт. Auth-lockout tests
проверяют 401 для неверных паролей, 429 на 10-й ошибке, `Retry-After=1800`,
истечение блокировки через 30 минут и очистку счётчика после успешного входа.
Prism smoke проверяет создание демонстрационного случая и вычисление
`c-obsidian.prism-evaluation/v1`. Docker-сборка и live readback этой правки не
выполнялись.

## Продолжение: 0.3.2-prism-api

Текущая редакция построена от 0.3.1-prism-authlock. Все native case API,
DSL, snapshots, история и блокировка входа сохранены. Добавлены UI создания
и копирования проектов, импорт/экспорт, HTML reference и API правок данных.
GET snapshot больше не создаёт события/файлы. Импорт проверяет model, protocol
и полный package SHA-256. Source entrypoint/run-services и Docker сохраняют
публичный RouterOS gateway режим; private runtime/certificates не копируются.
Сборка/установка нового образа и свежая live-проверка требуют отдельного
фактического результата и этим документом не подтверждаются.
