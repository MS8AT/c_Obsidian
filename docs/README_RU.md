# Начало работы · Русский

[Главная инструкция](../README.md) · [CLI](CLI.md) · [API](API.md)

Версия 0.2.1. [Логин и пароль на MikroTik](ACCOUNTS_RU.md) ·
[HTTPS и порт 18444 на RouterOS](ROUTEROS_HTTPS_RU.md).

1. Откройте локальную папку `c_Obsidian`.
2. Выполните `py -3 -B obsidian.py --lang ru serve --write --open`.
3. Выберите **RU**, **EN** или **中文** на закреплённой верхней панели.
4. Откройте «Рост идей», «Звёздное поле», «Притяжение», «Смысловые роли»
   или «Изображения» в левом меню.
5. Нажмите на заметку: справа появятся причина уровня, ссылки и оригинал.

Для заметки нажмите «+ Заметка», укажите, например, `Inbox/Новая идея.md`,
введите текст Markdown и нажмите «Создать». `[[Другая заметка]]` создаёт связь,
если такая заметка есть. При совпадении имён используйте полный путь.

Для фото нажмите «+ Изображение». Добавленный файл попадёт в `assets/`.
Появится готовая строка, например `![[assets/photo.jpg]]`. Вставьте её в новую
заметку; тогда изображение будет видно в галерее. Поддержаны PNG, JPEG, GIF,
WebP. Форматы с активным содержимым и веб-изображения не загружаются.

Своё хранилище: `py -3 -B obsidian.py --vault "C:\MyNotes" --lang ru serve --write --open`.
Для нового хранилища сначала `py -3 -B obsidian.py --vault "C:\MyNotes" init`.
Сканирование не изменяет заметки. Создание добавляет только новый файл.
Для остановки сервера нажмите `Ctrl+C` в его терминале.

Названия карт переведены в меню; текст заметок не переводится автоматически.
В наборе три иллюстрации, а не фотографии из присланного сообщения: сами
фотографии к сообщению не были приложены.
