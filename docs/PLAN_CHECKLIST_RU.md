# План, target и чеклист c_Obsidian

## Цель

Проверить весь API и CLI, опубликовать отдельный закрытый репозиторий,
собрать проверяемый контейнер linux/amd64 и развернуть приложение на RouterA
по адресу `https://obsidian.ms8at.by` через A1 с учётной записью `Domiteli`.
Пароль не входит в исходники, аргументы команд, журналы или контейнерный образ.

## Свежая сверка после попытки открытия порта

`obsidian.ms8at.by` разрешается в `93.125.6.89`, но TCP `18444` закрыт.
Свежий NAT readback RouterA не содержит правила `18444`; адрес `10.6.0.30:8443`
не отвечает. `www.obsidian.ms8at.by` остаётся NXDOMAIN. Порты 80/443 по-прежнему
принадлежат QR Station `10.6.0.20`. Полная квитанция:
`evidence/live-port-check-20261103.json`.

## План развёртывания

1. Проверить свободный IP и хеш контейнерного tar из зелёного CI.
2. Через штатный connector подготовить только app-owned файлы и отдельные
   пути vault/state/certificates. Никаких rootfs или секретов в SMB.
3. Добавить `veth-c-obsidian`, подключить к `Dockers`, импортировать контейнер
   с проверенным image SHA-256 и `OBSIDIAN_SHARED_GATEWAY=1`.
4. Ввод пользователя выполняется через защищённый TTY командой
   `python /app/auth_store.py --state /state --username Domiteli`.
   Приложение не запускает web listener, пока учётная запись не создана.
5. QR gateway остаётся владельцем A1:80/443. Добавить только новый
   `server_name obsidian.ms8at.by` и upstream `10.6.0.30:8080`.
   Сначала HTTP challenge, затем сертификат, затем TLS server block.
6. `nginx -t` перед каждым reload. Конкретный исполняемый путь и volume paths
   должны быть подтверждены текущим gateway inventory, не догадкой.
7. При любой ошибке остановить применение. Timeout/UNKNOWN не повторять без
   readback. Новые правила/файлы связывать ownership-именами и SHA-256.

## Откат

Вернуть только изменённые файлы gateway из точной preimage, выполнить config
test и reload. Остановить новый контейнер, отключить его autostart. Удалять
vault/state, общие NAT80/443, QR Station, чужие интерфейсы или файлы нельзя.
DNS-откат: восстановить preimage записи `obsidian`; не менять другие записи зоны.
