## Учётная запись c_Obsidian в контейнере

Команды `--action` доступны с **0.2.1**. Публикация исходников не обновляет уже
установленный контейнер 0.2.0: сначала нужен отдельно согласованный переход
на проверенный образ новой версии с сохранением `/state` и `/vault`.
Это учётная запись сайта, а не пароль администратора RouterOS.

В терминале WinBox посмотрите имя контейнера и откройте его оболочку:

```routeros
/container print
/container shell <container-name> user=app
```

Замените `<container-name>` точным именем вашего c_Obsidian. Далее команды
выполняются **внутри контейнера**, в приглашении `/app $`:

```sh
cd /app
# Изменить пароль существующего пользователя:
python /app/auth_store.py --state /state --username ExistingUser --action password --lang en
# Изменить логин и одновременно задать новый пароль:
python /app/auth_store.py --state /state --username ExistingUser --action rename --new-username NewUser --lang en
```

`ExistingUser` и `NewUser` — примеры: подставьте свои имена. Имя: 3–64 символа
`A–Z`, `a–z`, `0–9`, `.`, `_`, `-`. Новый пароль: 8–256 символов. Введите его
дважды; символы не отображаются. Если вводы различаются, ничего не меняется.
`--lang ru|en|zh` выбирает язык подсказок; `en` рекомендуется, если RouterOS
показывает кириллицу пробелами. Без защищённого ввода утилита останавливается.

Для **первого** создания используется `--action create` (действие по умолчанию).
Оно не перезаписывает существующий accounts.json. Смена пароля/логина сохраняет
других пользователей, атомарно заменяет файл с хешами и отзывает старые сессии.
Повторно войдите в браузере с новым логином/паролем; restart контейнера не нужен.
Пароль не передавайте в командной строке, чате или отчётах. Открытый пароль
не сохраняется: сохраните его сами в своём менеджере паролей.

Если существует `.accounts-update.lock`, другое управление могло не завершиться.
Сначала проверьте процессы и состояние операции; не удаляйте lock вслепую.

## Пользователь самого RouterOS / WinBox

Это отдельная учётная запись. В WinBox откройте **System → Users**, выберите
нужного пользователя и измените поле **Name** для логина. Для пароля используйте
**Password / Change Password** в карточке пользователя и введите новый пароль
дважды. Название кнопки зависит от версии WinBox. Сохраните изменения и
переподключитесь с новыми данными. Не меняйте Group/Policies ради смены пароля.

Изменение пользователя RouterOS не меняет вход в c_Obsidian и наоборот.
